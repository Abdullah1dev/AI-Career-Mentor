# 🎓 AI Career Mentor

An AI-powered career guidance chatbot built with **Python, Streamlit, and Google's Gemini API**.

AI Career Mentor is designed to help Computer Science students and early-career developers with career planning, learning roadmaps, AI/ML skills, project ideas, internship preparation, and technical interview guidance.

The project uses a custom **system prompt** to give the AI a dedicated career-mentor persona and keep its responses focused on technology and career development.

---

## 🚀 Features

- 🤖 AI-powered career guidance
- 🎯 Personalized career planning
- 📚 Learning roadmaps
- 💻 AI/ML project recommendations
- 🧠 Technology and skill guidance
- 📝 Interview preparation
- 💼 Internship preparation
- 💬 Interactive chat interface
- 🧠 Persistent conversation history during the session
- 🗑️ Clear chat functionality
- ⚠️ Error handling for API failures
- 🔐 API key stored securely using environment variables
- 🎭 Custom system prompt for a dedicated AI Career Mentor persona
